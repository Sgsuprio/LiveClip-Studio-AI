# LiveClip Studio AI

Turn a long video into vertical short clips — for real, for free.

**Live site:** https://sgsuprio.github.io/LiveClip-Studio-AI/

## How it works (no fake demo data)

1. **On the site:** paste a YouTube URL, pick clip length (15–30s / 30–60s / 60–90s),
   clip count and caption style (Hormozi / Minimal / Neon), then click
   **Generate Viral Clips**. The URL is copied for you — paste it into the
   GitHub form.
2. **On GitHub Actions (free, no files):** click **Open GitHub Actions**, pick
   the `main` branch, paste the same URL, keep the same settings, click
   **Run workflow**. The workflow (`.github/workflows/clip.yml`) runs the
   same pipeline as the Colab notebook — yt-dlp ingest, faster-whisper
   transcription, hook scoring, 9:16 render with styled captions — on a free
   runner (about 15–25 min for a 20-min segment), then publishes the results
   to the orphan `results` branch (`run_status.json` + `liveclip_clips.json`
   + clip MP4s/SRTs + `LiveClip_Export_Pack.zip`).
3. **Back on the site:** nothing to do — the page checks the `results` branch
   by itself every minute and the gallery fills with your real clips (real
   scores, transcripts, times, titles and hashtags). The real MP4s are linked
   on each card. Download Captions gives you real `.srt` files built from the
   transcription word timings.

**Colab still works as a fallback:** click **Open Colab Notebook** instead
(the settings travel with the link itself — nothing to download or upload),
pick a free T4 GPU runtime, then Run all. The notebook reads your settings
from the link, does the same pipeline, and packages the same files. If the
link ever loses the settings, the notebook falls back to an uploaded
`liveclip_config.json` (Download Config Again on the page), pasted JSON, or
the form fields in its first cell. Then click **Load Colab Results** and pick
`liveclip_clips.json`; the rendered MP4s are in the Colab export pack
(`LiveClip_Export_Pack.zip`).

The page itself never pretends to transcribe or render video — a static site
can't. The preview player on each card is an animated stand-in, clearly
labelled as a preview.

## Files

- `index.html` — the Studio web app (GitHub Pages).
- `clip.py` — the same pipeline as a standalone script (GitHub Actions
  backend). Generated by `build_clip.py` from `build_notebook.py` — do not
  edit by hand.
- `build_clip.py` — builds `clip.py` (`python3 build_clip.py`).
- `.github/workflows/clip.yml` — the Actions workflow (manual run from the
  site) + `.github/scripts/publish_results.sh` (publishes `results/` to the
  orphan `results` branch).
- `liveclip_colab.ipynb` — the real clipping pipeline (Google Colab).
- `build_notebook.py` — builds `liveclip_colab.ipynb` from readable Python
  source (`python3 build_notebook.py`). Edit the notebook here, not by hand.

## What the notebook does

- **Ingest:** downloads the source with yt-dlp (whole video, or one window up
  to 20 min, like Ssemble). Windowed downloads use direct stream URLs +
  ffmpeg stream-copy — `yt-dlp --download-sections` can silently truncate
  audio, so it is not used.
- **Transcribe:** faster-whisper (default `base`, word timestamps, VAD).
  Audio is decoded to a numpy array with ffmpeg first, because the file-path
  route breaks on some PyAV versions.
- **Score:** multi-signal hook scorer, 0–100 (speech density, hook words in
  the opener, questions, exclamations, numbers/stats, emotion words,
  sentence-boundary starts, speaking pace, silence-gap penalties). The
  Viral Hook Detection toggle switches the hook bonuses off for plain
  density ranking; Auto Silence Removal starts each clip at the first
  spoken word.
- **Render:** ffmpeg center-crop to 9:16, scale 1080×1920, `.ass` captions
  burned in with the chosen style, plus a real `.srt` per clip.
- **Package:** `liveclip_clips.json` (the results file the site loads) and
  `LiveClip_Export_Pack.zip` (MP4s + SRTs + results + config).

Use it for your own videos or content you have the right to clip.

## Verified

Tested end to end on a real 5-minute speech video (Denzel Washington,
“Fall Forward”): 3 clips scored 83/79/79, rendered as 1080×1920 30s MP4s
with burned-in captions, plus matching SRTs and `liveclip_clips.json`.
Page flow covered by a jsdom harness (30 checks: empty gallery on load,
auto-handoff link with the settings in the URL fragment and no file download,
real-results loading, word-timed SRT, export ZIP — plus the Actions flow:
handoff, pending-run memory, running/done/error status, auto-loaded clips
with real MP4 links). Notebook settings sources covered by a config-cell
test (link fragment, uploaded file, pasted JSON, form fields). The link
handoff uses a base64url JSON fragment (`#liveclip=...`) read by the
notebook with `google.colab.output.eval_js` — no third-party service is
involved, so there is nothing that can go down or block it. The standalone
`clip.py` (same stages, CPU transcription) was verified in the VM on the same
video: 3 clips scored 88/80/81, 1080×1920 MP4s with captions,
`run_status.json` running → done (about 8 min for the 5-min video on CPU).
